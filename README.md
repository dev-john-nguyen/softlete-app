# Softlete App
An iOS health and fitness application tailored for athletes and coaches to efficiently manage their training programs.

## Development
### App (IOS)
```
cd app
yarn install
cd ios
pod install
cd ...
yarn start
```

### Server
```
cd server
yarn install
yarn start
```
